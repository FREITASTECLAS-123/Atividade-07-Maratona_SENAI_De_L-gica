1. Diferencie variável de constante em um sistema de controle de
temperatura.

R:
Váriavel é o valor que pode mudar durante a execução do programa

Exemplo:
temperatura= 35°
A temperatura do ambiente pode aumentar ou diminuir, então ela é variável

Constante é um valor fixo, que não muda
       
Exemplo:
temperatura máxima permitida: 80°C
Esse limite foi definido pela empresa e permanece igual

3. Como funcionam os Operadores Lógicos (E / OU / NÃO) na segurança de
uma máquina?

Os operadores lógicos ajudam o sistema a tomar decisões.
As duas condições precisam ser verdadeiras.

Exemplo:

porta fechada E sensor ativo

Só assim a máquina liga.

OU (||)

Basta uma condição ser verdadeira.

Exemplo:

botão de emergência pressionado OU superaquecimento

A máquina será desligada.

NÃO (!)

Inverte o valor lógico.

Exemplo:

NÃO autorizado

Se o operador não estiver autorizado, o acesso é bloqueado.
